# Fly Away – Frontend

Frontend en React + TypeScript + Vite + Tailwind para la API de reserva de vuelos Fly Away.

## Cómo correrlo

1. Levantar el backend en `http://localhost:8080` (`./mvnw spring-boot:run` en su carpeta).
2. En esta carpeta:

```bash
npm install
npm run dev
```

3. Abrir `http://localhost:5173`.
